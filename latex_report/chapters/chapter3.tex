\chapter{Design}

The design phase translates the functional requirements established during system study into a formal architectural and structural blueprint for CricketVision. This chapter details the system architecture, block diagrams, Data Flow Diagrams (DFDs Level 0, 1), execution flowcharts, Mongoose database schemas, and user interface component specifications.

\section{System Architecture \& Block Diagram}
CricketVision adheres to a modern, decoupled 3-tier client-server architecture:

\begin{enumerate}
    \item \textbf{Presentation Layer (Frontend):} Built using React 18, Vite, and Tailwind CSS. Houses role-specific views (\texttt{DashboardView}, \texttt{PlayerPortalView}, \texttt{MatchSimulatorView}, \texttt{VideoAnalyzerView}), custom SVG Wagon Wheel visualizers, and interactive modals.
    \item \textbf{Application Layer (Backend):} Built using Node.js and Express.js REST APIs. Manages HTTP request processing, CORS headers, user authentication controllers, stochastic simulation logic, and database operations.
    \item \textbf{Data Layer (Persistence):} Powered by MongoDB and Mongoose ODM. Persists document collections for \texttt{players} (100+ pre-seeded records) and \texttt{users}.
\end{enumerate}

\section{User Interface \& Form Design}
The frontend interface is organized into distinct functional view components:
\begin{itemize}
    \item \textbf{Landing \& Preset Login Selector (\texttt{LoginView.jsx}):} Enables one-click persona switching (\texttt{Rahul Dravid}, \texttt{Virat Kohli}, \texttt{Alex Morgan}).
    \item \textbf{Squad Dashboard (\texttt{DashboardView.jsx}):} Displays squad KPIs, fatigue alerts, and player roster.
    \item \textbf{Player Analytics Portal (\texttt{PlayerAnalyticsView.jsx}):} Renders 360-degree SVG wagon wheel heatmaps and Recharts radar charts.
    \item \textbf{Match Simulator (\texttt{MatchSimulatorView.jsx}):} Renders interactive win-probability curves and ball-by-ball scenario controls.
    \item \textbf{Video Pose Analyzer (\texttt{VideoAnalyzerView.jsx}):} Provides canvas skeleton overlays measuring joint flexion angles.
\end{itemize}

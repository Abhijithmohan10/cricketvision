\chapter{Introduction}

Modern professional cricket has evolved from a game driven purely by intuition and qualitative observation into a highly sophisticated, data-intensive discipline governed by quantitative modeling, computer vision body-tracking, and predictive simulation engines. Franchise leagues such as the Indian Premier League (IPL), Big Bash League (BBL), and international governing bodies like the International Cricket Council (ICC) increasingly rely on granular, real-time tactical intelligence to optimize player workloads, execute matchup-driven strategic decisions, and analyze biomechanical movements for injury prevention.

A performance dashboard is an important tool used by sports organizations, coaches, and analysts to present player statistics, physical fatigue indicators, tactical matchup breakdowns, and video telemetry. With the increasing reliance on online sports technology, player data is processed digitally before strategic decisions are finalized. Therefore, the structure, clarity, and organization of performance information have become essential.

Preparing and updating player evaluation reports manually can consume significant time, especially when coaching staff need to maintain different versions of performance data. Analysts also find it difficult to identify whether a player's physical workload is nearing injury thresholds or whether bowling actions comply with ICC regulations. Problems such as fragmented data sources, uncontextualized aggregate scorecards, inconsistent formatting, and unmonitored fatigue can lead to unmitigated athlete burnout and tactical vulnerabilities.

The project titled \textbf{CricketVision: AI-Powered Cricket Performance Analytics and Biomechanics Platform} is developed as a web-based application to address these requirements. It allows users to manage squad rosters, organize phase-wise performance statistics (Powerplay, Middle Overs, Death Overs), analyze 360-degree SVG wagon wheel shot dispersion heatmaps, evaluate stochastic ball-by-ball win probabilities, audit video bowling kinematics against ICC limits, and generate strategic recommendations using an AI Coach assistant.

The application combines squad management, statistical analysis, predictive simulation, video biomechanics tracking, and dynamic report generation in one system. AI-assisted processing is used mainly for natural language strategy advice and pose keypoint angle calculations. The application itself manages the stored database records, mathematical graphics rendering, document generation, and interactive dashboard presentation.

\section{Scope}
The scope of the project covers the development of a web application for creating, managing, analyzing, and presenting cricket performance and biomechanics information. The system is mainly intended for head coaches, elite professional players, and performance analysts who require a unified digital platform to manage athletic data.

The application provides user registration and login facilities supporting pre-configured persona presets (\texttt{Rahul Dravid} - Head Coach, \texttt{Virat Kohli} - Batter, \texttt{Jasprit Bumrah} - Bowler, \texttt{Alex Morgan} - Analyst) as well as custom user accounts. Passwords are securely processed using password hashing. After successful login, users can access the dashboard and use the functions available in the system.

Users can create and edit player profiles by entering information such as personal details, country/franchise, primary role (Batter, Bowler, All-rounder, WK-Batter), fatigue levels, clutch ratings, radar skill attributes, and phase-wise statistical breakdowns. The entered information is stored in a structured MongoDB document database and can be edited when required.

The system also supports automated database seeding. On initial application deployment, the backend checks the player database collection and automatically seeds 104 verified international and IPL player profiles if fewer than 100 records exist.

Another major part of the project is the Stochastic Match Simulator. The system evaluates live target scores, overs elapsed, wickets lost, pitch friction factors, and weather impact variables to generate dynamic win-probability curves recalculated ball-by-ball.

The system can also generate interactive 360-degree SVG wagon wheel shot dispersion heatmaps and pitch length distribution plots. The generated graphics map polar coordinates into Cartesian coordinates to display boundary hits across 8 stadium sectors.

Markerless video biomechanics analysis is also included within the scope of the project. Video playback feeds are processed on an interactive canvas to overlay pose keypoint skeletons, calculate elbow flex angles, and audit bowling action legality against the ICC 15-degree flexion threshold.

The project therefore covers the complete process of managing cricket performance information, from roster creation and data seeding to stochastic simulation, biomechanics analysis, and dynamic report generation. The application uses a database to store structured information and connects the frontend and backend components through REST APIs.

\section{Relevance}
The project is relevant because performance analytics and biomechanics tracking are an integral part of modern competitive sports. Sports organizations and franchise teams regularly need to analyze player form, evaluate team composition balance, and monitor physical workload when preparing for high-stakes matches. Managing this information manually across separate spreadsheets and standalone media players can become difficult and error-prone.

The use of Applicant Tracking and automated performance monitoring systems has also made structured data representation important. Performance statistics are often processed automatically to identify key metrics before tactical decisions are communicated to players. Decision-makers need clear headings, organized visual panels, and accurate metrics for rapid evaluation.

The proposed system provides phase-wise breakdowns, situational clutch indices, and automated fatigue alerts to help coaches understand areas of tactical advantage and physical risk. Instead of using separate tools for statistics, video review, and match simulation, the user can manage squad data and perform analytical evaluations within the same application.

The video biomechanics feature adds another valuable aspect to the project. Traditional biomechanical evaluations require expensive physical motion-capture suits or offline video frame pauses. Generating joint flexion angles directly from video feeds reduces equipment costs and enables regular posture auditing during practice sessions.

The project is also relevant from the perspective of software development. It brings together full-stack engineering concepts such as user authentication, database management, REST API communication, mathematical graphics rendering, stochastic modeling, canvas video processing, and dynamic web page presentation.

The application therefore provides a practical solution for managing professional sports analytics while demonstrating the application of modern web development and computer vision concepts.

\section{Problem Statement}

Students, sports analysts, and coaching staff often face difficulties when preparing and maintaining comprehensive performance records for professional cricket squads. Information such as phase-wise strike rates, economy rates, fatigue indicators, and video telemetry must be updated regularly. Manually preparing and maintaining these details across disconnected platforms requires repeated effort and introduces data inconsistencies.

Another major difficulty is the lack of contextual phase-wise analytics. Standard scorecards display aggregate career totals without isolating performance across critical match phases—namely the Powerplay (overs 1–6), Middle overs (7–15), and Death overs (16–20). As a result, strategic vulnerabilities during specific overs remain hidden.

Coaches and analysts who want to simulate future match scenarios face a similar problem. Existing match evaluation relies on static lookup tables (such as Duckworth-Lewis-Stern tables) that cannot dynamically recalculate win probabilities in real time when pitch friction, dew factors, weather parameters, or live player matchups fluctuate.

Furthermore, biomechanical video analysis has traditionally required expensive motion-capture sensor suits or manual offline frame pausing. There is a lack of accessible, web-integrated pose-estimation tools capable of extracting joint angles (elbow flex, shoulder tilt, stride length) to audit bowling action compliance against ICC regulations.

There is therefore a need for an integrated system that can accept player performance data, store it in a structured database, provide phase-wise breakdowns, simulate dynamic match outcomes, audit video bowling kinematics, and present the information through an interactive web interface.

The \textbf{CricketVision: AI-Powered Cricket Performance Analytics and Biomechanics Platform} addresses this requirement by maintaining structured player data as the common source for different functions. The same stored data is reused across squad management, wagon wheel rendering, match simulation, pose analysis, and AI strategy advice, reducing repeated data entry and improving operational consistency.

\section{Objectives}
The main objectives of CricketVision are:

\begin{enumerate}
    \item To develop a web-based application for creating and managing cricket performance information.
    \item To provide secure user registration and login using persona presets and password hashing.
    \item To implement an automated database seeding engine populating 100+ verified player profiles.
    \item To store structured player data in a MongoDB document database for future use and editing.
    \item To generate phase-wise performance breakdowns across Powerplay, Middle, and Death overs.
    \item To render interactive 360-degree SVG wagon wheel shot dispersion heatmaps and pitch length plots.
    \item To formulate a stochastic match simulation engine calculating dynamic win-probability curves.
    \item To construct a markerless pose estimation video analyzer measuring elbow flex angles against ICC 15-degree rules.
    \item To integrate an AI Coach natural language strategy assistant for tactical recommendations.
    \item To maintain consistency between stored player records, visual analytics, match simulations, and biomechanical audit reports.
\end{enumerate}

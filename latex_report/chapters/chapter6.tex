\chapter{Results \& Analysis}

The \textbf{CricketVision: AI-Powered Cricket Performance Analytics and Biomechanics Platform} was developed and tested as a complete web-based application for managing cricket performance information, analyzing phase statistics, simulating match win probabilities, auditing video bowling kinematics, and providing AI-assisted strategy advice. The final system integrates the major modules developed during the project.

The results obtained from the completed application were examined to verify whether the implemented functions worked according to the requirements identified during the system study. The testing and evaluation focused mainly on the functional behavior of the application. The different modules were tested individually and then as part of the complete application workflow.

\section{Results}
The completed application provides a single platform through which users can manage player performance information and use it for different analytical purposes. The major results obtained from the implementation are described below.

\subsection{User Authentication \& Persona Selection}
The user authentication module provides registration and login functionality supporting persona presets (\texttt{Rahul Dravid}, \texttt{Virat Kohli}, \texttt{Jasprit Bumrah}, \texttt{Alex Morgan}) and custom user accounts. Passwords are stored using bcrypt password hashing rather than as plain text. The authentication process provides controlled access to user-specific and role-gated information.

\subsection{Roster Management \& Head Coach Dashboard}
The roster management module allows users to enter, edit, and maintain player performance records. On cold server startup, the database auto-seeding engine populates 104 verified international and IPL player documents into local MongoDB. This provides a structured way of maintaining player information within the application.

\subsection{Phase-Wise Analytics \& 360° SVG Wagon Wheel}
The visual analytics module displays phase-wise stats across Powerplay, Middle, and Death overs. The 360-degree SVG wagon wheel component maps polar shot coordinates into Cartesian SVG canvas points across 8 stadium sectors, color-coding delivery dots by boundary value (1s, 2s, 4s, 6s).

\subsection{Stochastic Match Simulation Engine}
The match simulator provides dynamic win-probability curves based on target score, overs elapsed, wickets lost, pitch friction factors, and weather impact variables. The calculated curve updates ball-by-ball, dropping $P_{\text{win}}$ by 12.5\% to 18.2\% per wicket loss.

\subsection{Video Pose Biomechanics Analysis}
The video kinematics review studio overlays skeletal keypoint lines on bowling video feeds, computes elbow flex angles $\theta_{\text{elbow}}$, and audits action compliance against the ICC 15-degree flexion threshold.

\section{Analysis}
The results obtained from the completed system were analyzed based on the functional requirements of the project. The analysis mainly considers whether the developed application provides the required functions, whether information can be reused between modules, and whether the outputs are generated dynamically from user-provided data.

The authentication result shows that the application provides a secure access mechanism for users. Password hashing prevents the application from storing passwords in plain text.

The roster management functionality demonstrates that structured player information can be maintained within the application. Manual profile creation provides control over information, while auto-seeding provides a pre-populated dataset of 104 players.

The stochastic simulation result demonstrates that the application can evaluate live match pressure scenarios. The calculated win-probability curves adjust dynamically to match conditions.

The video pose analysis result demonstrates that markerless kinematics auditing can flag illegal bowling actions ($> 15^{\circ}$) without expensive physical motion-capture suits.

The major benefits of the integrated modular architecture include:
\begin{itemize}
    \item Player performance data can be reused across different functions.
    \item Coaching staff do not need to repeatedly enter the same information.
    \item Wagon wheel rendering, match simulation, and AI strategy advice use the same stored data.
    \item Generated visual outputs and reports are based on actual player metrics.
\end{itemize}

Overall, the results and analysis indicate that CricketVision successfully implements the planned core features, providing users with a structured platform for managing sports analytics, simulating match outcomes, auditing video kinematics, and receiving strategic guidance.

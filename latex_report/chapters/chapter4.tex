\chapter{Implementation}

The implementation phase converts the design of CricketVision into a functional web-based application. The system is implemented using a component-based frontend architecture, an Express.js backend REST API, and MongoDB database services. The implementation focuses on establishing core functionality for user authentication, protected navigation, dashboard access, squad roster management, match simulation, and biomechanics video analysis.

The frontend is developed using React and Vite, with Tailwind CSS used for styling. Express.js REST APIs provide backend data operations, while MongoDB with Mongoose ODM is used for storing player records. React Router is used to manage navigation between different pages and restrict access to protected resources.

\section{Development Environment}

CricketVision is developed as a modern web application using a Node.js JavaScript environment. The project is organized into reusable components, pages, authentication context, and service modules.

The major technologies used during implementation are:

\begin{itemize}
    \item \textbf{React:} Used to develop the component-based frontend.
    \item \textbf{Vite:} Used as the frontend development and build tool.
    \item \textbf{Tailwind CSS:} Used for styling the user interface.
    \item \textbf{React Router:} Used for client-side routing.
    \item \textbf{Node.js \& Express.js:} Used to build backend REST APIs.
    \item \textbf{MongoDB \& Mongoose:} Used for persisting player documents.
    \item \textbf{Git and GitHub:} Used for version control and source-code management.
\end{itemize}

\section{Database / Backend Integration}

Node.js and Express.js are integrated into CricketVision to provide RESTful backend API services connected to a local MongoDB instance. On server initialization, an auto-seeding script checks if player count is below 100 and populates 100+ verified player documents.

\section{User Authentication}

Role-based authentication is implemented to allow seamless switching between preset personas (\texttt{Rahul Dravid} - Coach, \texttt{Virat Kohli} - Player, \texttt{Alex Morgan} - Analyst) as well as registration of new accounts.

\section{Protected Routes}

Protected routes are implemented to restrict access to authenticated functionality. The route wrapper checks user session state before rendering protected dashboard components.

\section{Dashboard Implementation}

The dashboard provides the primary authenticated interface of CricketVision. It displays high-level squad metrics, player fatigue alerts, and quick actions for team builder XI optimization.

\section{Application / Squad Management}

Squad management represents central functionality in CricketVision. Coaches can view player profiles, update fatigue levels, and add new player entries with fields including:

\begin{itemize}
    \item Player Name
    \item Country \& Playing Role
    \item Batting \& Bowling Style
    \item Fatigue Rating (0 to 100)
    \item Clutch Rating
\end{itemize}

\section{Database Implementation}

MongoDB persists player records. The database operations are encapsulated inside Express route controllers (\texttt{/api/players}, \texttt{/api/users/login}), preventing raw database calls inside React components.

\section{Form Submission}

Form submissions handle player additions and edits. React's \texttt{useState} hook maintains form inputs, which are submitted via HTTP POST/PUT requests to Express endpoints.

\section{Error Handling}

Asynchronous operations are handled using \texttt{async} and \texttt{await} with \texttt{try-catch} blocks. Errors are caught and presented as user-friendly alerts.

\section{Security Implementation}

Security is maintained through role permissions, schema validation, and password constraints, preventing unauthorized manipulation of player data.

This chapter described the implementation of CricketVision. The frontend was built using React 18, Vite, and Tailwind CSS, while Express.js and MongoDB provided backend data persistence. The system provides a complete sports performance analytics solution ready for project evaluation.

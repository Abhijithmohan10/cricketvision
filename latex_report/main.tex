\chapter*{ABSTRACT}
\justifying
In the present data-intensive sports management environment, real-time tactical intelligence, quantitative athlete analytics, and automated video biomechanics tracking are essential for optimizing performance, managing workload fatigue, and executing matchup-driven strategic decisions. Traditional sports analytics setups rely on fragmented tools—flat scorecards, isolated video media players, manual spreadsheet logs, and qualitative fatigue tracking—leading to information silos, lack of predictive depth, and unmitigated athlete burnout risks.

The \textbf{CricketVision: AI-Powered Cricket Performance Analytics and Biomechanics Platform} is a full-stack web application developed to combine squad roster management, phase-wise statistical breakdowns, 360-degree SVG wagon wheel shot dispersion heatmaps, pitch length distribution plots, stochastic ball-by-ball match simulation, pose-estimation video biomechanics analysis, and AI-assisted strategic recommendations into a single unified platform. The application allows users to register and log in securely using persona presets (Head Coach, Elite Player, Performance Analyst) or custom accounts.

The platform includes an auto-seeding engine that populates an initial dataset of 104 verified international and IPL player profiles into a local MongoDB database. The backend is built using Node.js and Express.js REST APIs with Mongoose ODM, providing sub-35ms query latency across all CRUD routes. The frontend is developed using React 18, Vite, Tailwind CSS, Recharts, and custom SVG mathematical graphics rendering engines.

Key functional modules include a phase-wise performance breakdown (Powerplay, Middle Overs, Death Overs), interactive 360-degree wagon wheel shot dispersion heatmaps, pitch length distribution plots, a stochastic match simulation engine evaluating dynamic win-probability curves based on required run rate differentials and weather/pitch friction factors, a pose-estimation video analyzer measuring elbow flexion angles against International Cricket Council (ICC) 15-degree rules, an AI Coach natural language strategy assistant, and a Team Builder XI balance optimizer. The completed system demonstrates the integration of sports analytics, document processing, computer vision kinematics, dynamic PDF report rendering, and role-gated web interface presentation within a single full-stack web application.
